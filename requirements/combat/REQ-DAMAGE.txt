==================================================
REQ-DMG-01
==================================================

Negative finale Schadenswerte sind ungültig.



==================================================
REQ-DMG-02
==================================================

Rüstung reduziert finalen Schaden multiplikativ.



==================================================
REQ-DMG-03
==================================================

Durchdringung verwendet eigenen Schadensmultiplikator.

0 entspricht keinem Bonus.
Werte größer 0 erhöhen den eingehenden Schaden.



==================================================
REQ-DMG-04
==================================================

Counterboni werden multiplikativ angewendet.

Ein Schiff kann mehrere Counterbeziehungen besitzen.

Existieren mehrere gültige Counterziele,
wird der höchste gültige Countermultiplikator verwendet.



==================================================
REQ-DMG-05
==================================================

Alle gültigen Angriffe einer Kampfrunde
werden gleichzeitig berechnet.

Verluste werden erst nach Abschluss aller Schadensberechnungen angewendet.



==================================================
REQ-DMG-06
==================================================

Alle Schadenswerte werden intern präzise berechnet.

Erst der finale aggregierte Gesamtschaden
wird mathematisch auf ganze Zahlen gerundet.



==================================================
REQ-DMG-07
==================================================

Overflow-Schaden
kann innerhalb derselben Kampfrunde
weitere Zieltypen angreifen.



==================================================
REQ-DMG-08
==================================================

Bei jedem Zielwechsel
müssen Zielmultiplikatoren
vollständig neu berechnet werden.

Vorherige Zielmultiplikatoren
dürfen keinen Einfluss
auf neue Zieltypen besitzen.



==================================================
REQ-DMG-09
==================================================

Gleiche Kampfsituationen
müssen identische Kampfergebnisse erzeugen.



==================================================
REQ-DMG-10
==================================================

Defeinheiten
verwenden dieselbe Schadensberechnung
wie Schiffe.



==================================================
REQ-DMG-11
==================================================

Finale Verluste
müssen deterministisch
aus dem finalen Gesamtschaden berechnet werden.



==================================================
REQ-DMG-12
==================================================

Gleiche Kampfsituationen
müssen identische Zielpriorisierung erzeugen.



==================================================
REQ-DMG-13
==================================================

Pro Spielerflotte
darf maximal einmal
ein 5%-Overflowverlust ausgelöst werden.

Der 5%-Overflowverlust
wird ausgelöst:
- beim ersten Schifftypwechsel
ODER
- beim Übergang auf eine neue Spielerflotte.

Innerhalb derselben Spielerflotte
darf danach kein weiterer
5%-Overflowverlust ausgelöst werden.
