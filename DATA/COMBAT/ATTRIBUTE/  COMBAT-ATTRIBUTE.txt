==================================================
GRUNDATTRIBUTE
==================================================

--------------------------------------------------
Trefferpunkte
--------------------------------------------------

Definition:
Maximale Schadensmenge,
die eine Einheit
vor Zerstörung aufnehmen kann.

Verwendung:
- Schadensberechnung
- Verlustberechnung
- Overflowberechnung
- Result
- UI
- Log

Beispiel:
500 Trefferpunkte



--------------------------------------------------
Schaden
--------------------------------------------------

Definition:
Basisschaden,
den eine Einheit
pro Kampfrunde verursacht.

Verwendung:
- Damagepipeline
- Counterberechnung
- Overflow
- Result
- Log

Beispiel:
120 Schaden



--------------------------------------------------
Rüstung
--------------------------------------------------

Definition:
Multiplikativer Schadensreduktionswert
einer Einheit.

Verwendung:
- Damagepipeline
- Schadensreduktion

Formel:
0.85
=
15% Schadensreduktion

Beispiel:
15 Rüstung
=
0.85 Schadensmultiplikator



--------------------------------------------------
Durchdringung
--------------------------------------------------

Definition:
Multiplikativer Schadensverstärkungswert
gegen gepanzerte Ziele.

Verwendung:
- Damagepipeline
- Schadensverstärkung

Formel:
1.20
=
20% Schadensverstärkung

Beispiel:
20 Durchdringung
=
1.20 Schadensmultiplikator



--------------------------------------------------
Volumen
--------------------------------------------------

Definition:
Raumwert einer Einheit
zur Berechnung
des Gesamtvolumens aktiver Kampfparteien.

Verwendung:
- Targetpriorisierung
- Flottenvolumen
- UI
- Result

Beispiel:
Abfangjäger
=
5 Volumen





==================================================
TARGETATTRIBUTE
==================================================

--------------------------------------------------
Zieltyp
--------------------------------------------------

Definition:
Combatkategorie,
gegen die Einheiten
priorisiert werden können.

Verwendung:
- Targetsystem
- Zielpriorisierung
- Counterlogik
- Log
- UI

Beispiel:
- Leichtes Schiff
- Schweres Schiff
- Defeinheit



--------------------------------------------------
Counterbeziehungen
--------------------------------------------------

Definition:
Definiert,
gegen welche Zieltypen
eine Einheit
verstärkten Schaden verursacht.

Verwendung:
- Countermultiplikator
- Zielpriorisierung
- Damagepipeline
- UI

Beispiel:
Bomber
→ stark gegen schwere Schiffe



--------------------------------------------------
Verwundbarkeiten
--------------------------------------------------

Definition:
Definiert,
welche Einheitentypen
verstärkten Schaden
gegen diese Einheit verursachen.

Verwendung:
- UI
- Kampfanalyse
- Balancing
- Targetanalyse

Beispiel:
Schweres Schiff
→ verwundbar gegen Bomber





==================================================
COMBATSTATUS
==================================================

--------------------------------------------------
aktiv
--------------------------------------------------

Definition:
Eine Einheit,
die aktuell
am Kampf teilnimmt.

Verwendung:
- Damagepipeline
- Zielsystem
- Flottenvolumen
- Result
- Log
- UI

Beispiel:
Aktive Schiffe
verursachen Schaden
und können angegriffen werden.



--------------------------------------------------
beschädigt
--------------------------------------------------

Definition:
Ein Schiff,
das den Kampf überlebt hat,
aber nicht mehr
zur aktiven Flotte zählt.

Verwendung:
- Result
- UI
- Werkstatt
- Warp

Beispiel:
Beschädigte Schiffe
werden gelb dargestellt.



--------------------------------------------------
zerstört
--------------------------------------------------

Definition:
Eine Einheit,
die vollständig vernichtet wurde
und nicht mehr existiert.

Verwendung:
- Verlustberechnung
- Result
- UI
- Log

Beispiel:
Zerstörte Einheiten
werden rot dargestellt.





==================================================
COMBATROLLEN
==================================================

--------------------------------------------------
Angreifer
--------------------------------------------------

Definition:
Die aktive Kampfpartei,
die einen Kampf initiiert.

Verwendung:
- Combatstart
- Result
- Log
- UI
- Kampfzuordnung

Beispiel:
Eine angreifende Flotte
greift eine gegnerische Flotte
oder Defeinheiten an.



--------------------------------------------------
Verteidiger
--------------------------------------------------

Definition:
Die angegriffene Kampfpartei,
die auf einen Angriff reagiert.

Verwendung:
- Combatstart
- Result
- Log
- UI
- Kampfzuordnung

Beispiel:
Eine verteidigende Flotte
verteidigt einen Planeten
oder eine Position.





==================================================
EINHEITENTYPEN
==================================================

--------------------------------------------------
Schiff
--------------------------------------------------

Definition:
Mobile Kampfeinheit,
die aktiv an Flottenkämpfen teilnimmt.

Verwendung:
- Damagepipeline
- Flottenvolumen
- Warp
- Werkstatt
- Result
- Log
- UI

Besonderheiten:
- kann beschädigt werden
- kann zerstört werden
- kann in Warp/Werkstatt wechseln

Beispiel:
- Abfangjäger
- Kreuzer
- Bomber



--------------------------------------------------
Defeinheit
--------------------------------------------------

Definition:
Stationäre Kampfeinheit
zur Verteidigung
einer Position oder eines Planeten.

Verwendung:
- Damagepipeline
- Defvolumen
- Result
- Log
- UI

Besonderheiten:
- kein Warpstatus
- kein Werkstattstatus
- bleibt stationär

Beispiel:
- Laserturm
- Raketenabwehr
- Schildgenerator





==================================================
MULTIPLIKATOREN
==================================================

--------------------------------------------------
Schiffstechmultiplikator
--------------------------------------------------

Definition:
Technologiebasierter Verstärkungsmultiplikator
für Schiffe.

Verwendung:
- Damagepipeline
- Schadensverstärkung
- Schiffsbalancing

Besonderheiten:
- wirkt nur auf Schiffe
- getrennt von Deftechs

Beispiel:
+20% Schiffsschaden
=
1.20 Multiplikator



--------------------------------------------------
Deftechmultiplikator
--------------------------------------------------

Definition:
Technologiebasierter Verstärkungsmultiplikator
für Defeinheiten.

Verwendung:
- Damagepipeline
- Schadensverstärkung
- Defbalancing

Besonderheiten:
- wirkt nur auf Defeinheiten
- getrennt von Schiffstechs

Beispiel:
+15% Defschaden
=
1.15 Multiplikator



--------------------------------------------------
Countermultiplikator
--------------------------------------------------

Definition:
Schadensverstärkender Multiplikator
gegen gültige Counterziele.

Verwendung:
- Damagepipeline
- Targetsystem
- Combatbalancing

Besonderheiten:
- wird pro Zielwechsel neu berechnet
- verwendet den höchsten gültigen Counter

Beispiel:
Bomber
gegen schweres Schiff
=
1.50 Multiplikator



--------------------------------------------------
Rüstungsmultiplikator
--------------------------------------------------

Definition:
Multiplikativer Schadensreduktionswert
eines Ziels.

Verwendung:
- Damagepipeline
- Schadensreduktion

Besonderheiten:
- wird nach Durchdringung angewendet

Beispiel:
15 Rüstung
=
0.85 Multiplikator



--------------------------------------------------
Durchdringungsmultiplikator
--------------------------------------------------

Definition:
Multiplikativer Schadensverstärkungswert
gegen gepanzerte Ziele.

Verwendung:
- Damagepipeline
- Schadensverstärkung

Besonderheiten:
- wird vor Rüstung angewendet

Beispiel:
20 Durchdringung
=
1.20 Multiplikator



--------------------------------------------------
VIP-Multiplikator
--------------------------------------------------

Definition:
Globaler Verstärkungsmultiplikator
durch VIP-Boni.

Verwendung:
- Damagepipeline
- globale Verstärkung

Besonderheiten:
- kann mehrere Combatwerte beeinflussen

Beispiel:
VIP-Schadensbonus
=
1.10 Multiplikator



--------------------------------------------------
Energonmultiplikator
--------------------------------------------------

Definition:
Globaler Verstärkungsmultiplikator
durch Energonverstärkung.

Verwendung:
- Damagepipeline
- globale Verstärkung

Besonderheiten:
- kann mehrere Combatwerte beeinflussen

Beispiel:
Energonbonus
=
1.25 Multiplikator





==================================================
COMBATERGEBNISSE
==================================================

--------------------------------------------------
finaler Schaden
--------------------------------------------------

Definition:
Gesamter finaler Schaden,
der nach vollständiger Schadensberechnung
verursacht wurde.

Verwendung:
- Result
- Log
- UI
- Kampfanalyse

Besonderheiten:
- beinhaltet alle Multiplikatoren
- beinhaltet Counter
- beinhaltet Overflow

Beispiel:
125000 finaler Schaden



--------------------------------------------------
finale Verluste
--------------------------------------------------

Definition:
Gesamtanzahl vollständig zerstörter Einheiten
nach Abschluss des Kampfes.

Verwendung:
- Result
- UI
- Log
- Verlustanalyse

Besonderheiten:
- zerstörte Einheiten
zählen nicht mehr
zur aktiven Kampfpartei

Beispiel:
120 zerstörte Abfangjäger



--------------------------------------------------
finale beschädigte Einheiten
--------------------------------------------------

Definition:
Anzahl beschädigter Schiffe,
die den Kampf überlebt haben,
aber nicht mehr
zur aktiven Flotte zählen.

Verwendung:
- Result
- UI
- Werkstatt
- Warp

Besonderheiten:
- nur für Schiffe
- nicht für Defeinheiten

Beispiel:
35 beschädigte Kreuzer



--------------------------------------------------
verbleibende Einheiten
--------------------------------------------------

Definition:
Einheiten,
die nach Abschluss des Kampfes
weiterhin aktiv verfügbar sind.

Verwendung:
- Result
- UI
- Log
- Flottenstatus

Besonderheiten:
- beschädigte Einheiten
zählen nicht dazu

Beispiel:
250 verbleibende Abfangjäger



--------------------------------------------------
Kampfrundenanzahl
--------------------------------------------------

Definition:
Gesamtanzahl berechneter Kampfrunden
eines Kampfes.

Verwendung:
- Result
- Log
- UI
- Kampfanalyse

Besonderheiten:
- technisch auf 250 Runden begrenzt

Beispiel:
12 Kampfrunden



--------------------------------------------------
Siegerstatus
--------------------------------------------------

Definition:
Kennzeichnet die Kampfpartei,
die den Kampf gewonnen hat.

Verwendung:
- Result
- UI
- Log

Beispiel:
Angreifer gewinnt



--------------------------------------------------
Verliererstatus
--------------------------------------------------

Definition:
Kennzeichnet die Kampfpartei,
die den Kampf verloren hat.

Verwendung:
- Result
- UI
- Log

Beispiel:
Verteidiger verliert



--------------------------------------------------
Unentschiedenstatus
--------------------------------------------------

Definition:
Kennzeichnet einen Kampf,
bei dem keine Kampfpartei
den Sieg erreicht hat.

Verwendung:
- Result
- UI
- Log

Besonderheiten:
- möglich bei Kampfrundenlimit
- möglich bei vollständiger gegenseitiger Zerstörung

Beispiel:
Kampf endet unentschieden



--------------------------------------------------
Beute
--------------------------------------------------

Definition:
Ressourcen,
die nach einem erfolgreichen Kampf
erbeutet werden.

Verwendung:
- Result
- UI
- Wirtschaftssystem

Beispiel:
- Metall
- Kristall
- Gas



--------------------------------------------------
Trümmer
--------------------------------------------------

Definition:
Ressourcen,
die aus zerstörten Einheiten entstehen
und direkt ins Inventar übertragen werden.

Verwendung:
- Result
- Wirtschaftssystem

Besonderheiten:
- kein persistentes Trümmerfeld

Beispiel:
5000 Metalltrümmer





==================================================
LOGATTRIBUTE
==================================================

--------------------------------------------------
dargestellte Kampfrunde
--------------------------------------------------

Definition:
Eine im Kampflog sichtbare Kampfrunde.

Verwendung:
- Log
- UI
- Kampfanalyse

Besonderheiten:
- Spieler sieht nur:
  - erste 5 Kampfrunden
  - letzte 2 Kampfrunden

Beispiel:
Kampfrunde 3



--------------------------------------------------
angegriffener Zieltyp
--------------------------------------------------

Definition:
Der Zieltyp,
der innerhalb einer dargestellten Kampfrunde
angegriffen wurde.

Verwendung:
- Log
- UI
- Kampfanalyse

Beispiel:
Bomber greifen schwere Schiffe an



--------------------------------------------------
dargestellter Schaden
--------------------------------------------------

Definition:
Der in einer dargestellten Kampfrunde
sichtbare verursachte Schaden.

Verwendung:
- Log
- UI
- Kampfanalyse

Besonderheiten:
- basiert auf RESULT-Daten

Beispiel:
12500 Schaden



--------------------------------------------------
dargestellte Verluste
--------------------------------------------------

Definition:
Die in einer dargestellten Kampfrunde
sichtbaren zerstörten Einheiten.

Verwendung:
- Log
- UI
- Kampfanalyse

Beispiel:
15 zerstörte Kreuzer



--------------------------------------------------
dargestellte verbleibende Einheiten
--------------------------------------------------

Definition:
Die nach einer dargestellten Kampfrunde
noch aktiven Einheiten.

Verwendung:
- Log
- UI
- Kampfanalyse

Beispiel:
120 verbleibende Abfangjäger

- UI

20 zerstörte Kreuzer

zur aktiven Flotte zählen.

15 beschädigte Bomber



--------------------------------------------------
Beuteanzeige

--------------------------------------------------
Siegeranzeige

- UI
