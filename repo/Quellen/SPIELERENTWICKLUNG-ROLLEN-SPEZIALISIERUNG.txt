# SPIELERENTWICKLUNG / ROLLEN / SPEZIALISIERUNG / LANGZEITIDENTITÄT
AKTUELLER STAND

==================================================
1. KERNIDENTITÄT
STATUS: WEITGEHEND DEFINIERT
==================================================

SPIELERENTWICKLUNG SOLL:
- langfristige Identität erzeugen
- Veteranenkultur stärken
- soziale Rollen ermöglichen
- Spezialisierung fördern
- Wissen wertvoll machen
- Gemeinschaftsabängigkeit erzeugen
- unterschiedliche Machtformen ermöglichen
- operative Verwundbarkeit erhalten
- individuelle Geschichten ermöglichen

SPIELER SOLLEN NICHT:
- nur größere Zahlen werden
- austauschbar sein
- alle dieselbe Rolle spielen
- vollständig optimierbar sein

WICHTIG:
Macht ist situationsabhängig.
Keine einzelne Machtquelle soll automatisch alles dominieren.

BEISPIELE:
- Kampfkraft ohne Versorgung = temporär
- Sicht ohne Schlagkraft = begrenzt
- Wirtschaft ohne Schutz = verwundbar
- Organisation ohne Spezialisten = ineffizient
- Mobilität ohne Versorgung = riskant

ZIEL:
gegenseitige Abhängigkeit zwischen Rollen.

==================================================

- Richtungsentscheidungen
- langfristige Entwicklung

MÖGLICHE SPEZIALISIERUNGEN:
- Angriff
- Verteidigung

- Mobilität
- Werkstatt
- Wirtschaft
- Transport
- Aufklärung
- territoriale Kontrolle
- Reaktionsfähigkeit
- Versorgung

WICHTIG:
Spezialisierungen sollen:
- Stärken
UND
- Schwächen
erzeugen.

ZIEL:
keine Universalbuilds.

AKTUELLER STAND:
- langfristige Exklusivität geplant
- Energon extrem langfristig

OFFENE FRAGE:
- Können absolute Langzeitspieler irgendwann trotzdem alles maxen?
- Braucht es aktive Spezialisierungsslots oder Fokuslimits?

5. SOZIALE BEDEUTUNG
STATUS: STARK DEFINIERT
==================================================

NICHT JEDER SPIELER IST GLEICH WICHTIG.

BEDEUTUNG ENTSTEHT DURCH:
- Aktivität
- Organisation
- Kompetenz
- Loyalität
- Hilfsbereitschaft
- strategische Relevanz
- soziale Beziehungen
- Zuverlässigkeit

VERTEIDIGUNG:
ist keine automatische Pflicht,
sondern soziale Entscheidung.

FRAGEN:
- Lohnt sich die Verteidigung?
- Ist der Spieler wichtig?
- Ist der Spieler zuverlässig?
- War er früher selbst hilfsbereit?
- Ist die Position strategisch wichtig?

KONSEQUENZ:
Vertrauen wird reale soziale Währung.

8. BLITZKRIEG / REAKTIONSKRIEG
STATUS: TEILWEISE DEFINIERT
==================================================

BLITZKRIEG SOLL MÖGLICH SEIN.

ABER:
Flotten müssen einzeln geschickt werden.

KONSEQUENZEN:
- keine perfekte Gleichzeitsynchronisation
- operative Staffelung
- Reaktionsfenster bleiben bestehen

BEISPIEL:
7 Flotten
≈ jeweils 2-4 Sekunden Versandzeit

KONSEQUENZEN:
- Verbündete können reagieren
- zweite Verstärkungswellen möglich
- menschliche Fehler bleiben relevant
- Angriffe bleiben chaotisch

WICHTIG:
Perfekte mathematische Mobilisierung soll verhindert werden.

OFFENE FRAGE:
- Wie stark darf Blitzkrieg später wirklich werden?
- Wie verhindert man Schlaf-/24h-Zwang?

15. AFK / RÜCKKEHRER
STATUS: DEFINIERT
==================================================

AFK-SPIELER:
blockieren langfristig keinen Raum.

PLANETEN:
werden nach ca. 60 Tagen oder nach Merge freigegeben.

RÜCKKEHRER:
- werden reintegriert
- erhalten neue Platzierung
- sollen keine aktiven Hubs zerstören
- erhalten Teleport
- erhalten temporären Schutzschild

ZIEL:
Persistenz ohne Weltblockierung.
